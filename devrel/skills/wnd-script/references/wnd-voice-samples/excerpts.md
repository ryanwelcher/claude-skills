## Report-and-point items (what it is → what changed → who it's for → go look)

- "First up is the responsive grid block with set columns. So previously, when you were using the grid block, you had to pick one or the other. Either you could set a minimum column width for responsive stuff, or you could set a fixed column count. You couldn't do both at the same time. With Gutenberg 22.3, you can combine both controls. ... This is really great for theme developers and anyone doing layout work." (Jan)
- "Next is the dedicated font library admin screen. If you've ever tried to manage fonts in WordPress, you know it's buried deep in the styles UI. Not exactly easy to find. Well, now there's an appearance font screen right in the admin." (Jan)
- "Block Visibility Controls introduced conditional display. This is something people have been asking for for a very long time." (Oct)
- "The content only template lock now supports inserting content blocks inside defined areas, which is really great for theme authors, but it does mean that the block insertion logic has changed, so you should absolutely test out your themes and everything on this during the 7.0 cycle just to make sure there aren't any unexpected bugs."
