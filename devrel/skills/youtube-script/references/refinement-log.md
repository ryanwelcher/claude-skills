- 2026-08-10 — **"and honestly," is off-voice.** Flagged in the WP 7.1 Custom Icons script: "so I've got a bit of a personal stake in this one — **and honestly**, being able to register your own icons is the thing it was missing." Approved fix: **"I actually helped get the Icon block into 7.0, so I've got a personal stake in this one. And I'm pretty happy to see this land, because it makes the block that much more powerful."** Generalize to the whole sincerity-adverb family ("truly", "I'll be honest", "to be fair") — same root as the banned `genuinely` (→ Verbal tics).
