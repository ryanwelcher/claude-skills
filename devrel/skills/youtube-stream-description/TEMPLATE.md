## Hashtag rules

**Base set (always include):**

```
#wordpress #wordpresstutorial #coding #customblocks #javascript #php #gutenberg #livestream
```

**Topic-specific additions** are allowed when the stream clearly diverges from the usual blocks/Gutenberg focus. Examples:

- React-heavy stream → add `#react`
- Interactivity API stream → add `#interactivityapi`
- Block theme work → add `#blocktheme`

Keep total hashtags reasonable (under ~10). Default to consistency with recent descriptions over novelty.
